My Journey into Web Development

My journey into web development began with learning the fundamentals of HTML and understanding how webpages are structured. I then explored CSS and learned how to transform simple webpages into attractive and responsive designs.

After building a strong foundation in HTML and CSS, I started learning JavaScript to make websites more interactive and dynamic. Along the way, I began creating my own projects and sharing what I learned with other students.

My interest in both development and teaching led me to start Tech-Forge, where I aim to create a learning environment for students who want to explore web development and technology.
